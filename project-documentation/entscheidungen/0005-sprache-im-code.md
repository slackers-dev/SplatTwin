# 0005: Bezeichner Englisch, Kommentare und Doku Deutsch

- **Status:** angenommen
- **Datum:** 25.11.2026
- **Beteiligt:** Team

## Ausgangslage

Der Code war gemischt. Für die Arbeit zu zweit braucht es eine feste Regel.

## Entscheidung

- Bezeichner (Variablen, Funktionen, Dateien im Code) auf Englisch.
- Kommentare im Code auf Deutsch, ohne Umlaute (`ae`, `oe`, `ue`).
- Texte für Benutzer und die Doku auf Deutsch mit Umlauten.
- Commits nach Conventional Commits mit deutscher Beschreibung.

## Betrachtete Alternativen

- **Alles Englisch:** Das Modul und das Team arbeiten auf Deutsch, Fachbegriffe wie im Modul.
